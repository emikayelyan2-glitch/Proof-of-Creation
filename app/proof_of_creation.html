THE PROBLEM

Unprotected Intellectual Property Vulnerabilities.

Traditional registration can be slow and expensive, while early-stage work can leak before public launch. In disputes, creators need a tamper-proof proof of prior existence.

01

Slow & Expensive

Traditional copyright registration takes months and hundreds of dollars per item.

02

Early-Stage Leakage

Draft artwork, 3D designs, and raw code snippets can be stolen prior to public launch.

03

Weak Proof Burden

Proving prior existence in disputes requires tamper-proof cryptographic timestamps.

THE SOLUTION

Cryptographic Ownership Proof.

1. Zero Privacy Leakage

Client-side SHA-256 hashing ensures files never leave browser memory.

2. Immutable On-Chain PDA

Stores fingerprint, author pubkey, and Unix timestamp on Solana ledger.

3. Verifiable Certificate

Generates printable PDF/QR certificate tied directly to transaction signature.

ARCHITECTURE

Deterministic by design.

The on-chain record centers on a deterministic Solana PDA and a compact proof account structure.

1
Hash locallyCompute SHA-256 in the browser without uploading the file.
2
Bind the proofCombine creator public key + file fingerprint into deterministic PDA seeds.
3
Timestamp on SolanaUse the native Clock / Proof-of-History time source for the ledger record.
4
Verify laterMatch the same fingerprint against the immutable on-chain proof and certificate.
ProofAccount {
  creator: Pubkey,      // 32 bytes
  file_hash: [u8; 32], // SHA-256
  timestamp: i64,       // Unix timestamp
  metadata_uri: String,
  bump: u8
}

Seeds = [
  b"proof",
  creator_pubkey,
  file_hash
]

// prevents duplicate registrations
// native Solana Clock for timestamping
